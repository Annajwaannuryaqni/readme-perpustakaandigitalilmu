📚 Perpustakaan Digital Ilmu Sistem Informasi Perpustakaan Sekolah Berbasis Web

PHP Native · MariaDB / MySQL · PDO · Tailwind CSS · Chart.js

Tentang · Fitur · Teknologi · Dokumentasi Visual · Instalasi

📖 Tentang Project Perpustakaan Digital Ilmu adalah aplikasi web untuk membantu pengelolaan perpustakaan sekolah secara digital. Sistem mencakup katalog buku, data anggota, peminjaman, pengembalian, presensi kunjungan, rating dan komentar buku, notifikasi, serta pengelolaan data melalui akun Admin dan Petugas. Project menggunakan PHP Native sebagai backend dan MariaDB/MySQL sebagai database dengan PDO untuk koneksi dan query database. ✨ Fitur Utama
👤 Pengunjung Melihat halaman utama dan katalog. Melihat kategori dan detail buku. Melihat rating dan komentar. Mengakses halaman bantuan. 🎓 Siswa / Anggota Registrasi dan login. Melihat dashboard. Meminjam dan mengembalikan buku. Melihat bukti peminjaman. Mendapatkan perhitungan denda. Memberikan rating dan komentar. Melakukan presensi. Menerima notifikasi. 🛠️ Petugas Login dan logout. Melihat dashboard. Memproses peminjaman dan pengembalian. Melihat data buku dan anggota. Melihat buku terlambat. Melihat aktivitas transaksi. Mengelola profil. 👑 Admin Melihat dashboard dan statistik. CRUD data buku. CRUD data anggota. Mengelola transaksi. Mengelola akun petugas. Melihat data kunjungan. Mencetak laporan transaksi.

🔗 Relasi Utama buku.id_kategori → kategori.id_kategori transaksi.id_anggota → anggota.id_anggota transaksi.id_petugas → petugas.id_petugas transaksi.id_buku → buku.id_buku rating → buku, anggota, dan transaksi komentar → buku, anggota, dan transaksi kunjungan.id_anggota → anggota.id_anggota Detail hubungan antar-entitas tersedia pada ERD. 🔐 Keamanan Project menerapkan beberapa mekanisme keamanan: PDO Prepared Statement untuk query database. Password Hashing menggunakan password_hash() dan password_verify(). Session & Role Protection melalui includes/auth.php. CSRF Protection pada request yang mengubah data. Database Transaction pada proses peminjaman. Penguncian data buku menggunakan FOR UPDATE pada proses peminjaman.
