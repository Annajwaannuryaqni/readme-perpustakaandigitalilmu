01 — Ringkasan

Tentang Project

Aplikasi manajemen perpustakaan sekolah berbasis web, dibangun dengan PHP native + MySQL. Digunakan untuk mengelola koleksi buku, pendaftaran anggota (siswa), serta proses peminjaman dan pengembalian buku secara digital — lengkap dengan denda keterlambatan otomatis serta rating & ulasan buku.

Proyek ini dikerjakan sebagai tugas UKK (Uji Kompetensi Keahlian) SMK Konsentrasi Rekayasa Perangkat Lunak, "Pengembangan Aplikasi Peminjaman Buku".

02 — Ringkasan

Fitur Utama

  • Katalog buku publik dengan kategori & grafik statistik, dapat diakses tanpa login
  • Peminjaman buku: pilih buku → konfirmasi stok → bukti peminjaman digital
  • Pengembalian buku dengan perhitungan denda keterlambatan otomatis
  • Rating & komentar buku, dapat diisi setelah buku dikembalikan
  • Presensi kunjungan untuk siswa yang membaca di tempat tanpa meminjam
  • Notifikasi in-app untuk admin, siswa, dan petugas
  • CRUD buku, anggota, dan transaksi, lengkap dengan cetak laporan (panel admin)
03 — Ringkasan

Peran Pengguna

Sistem melayani empat jenis pengguna dengan hak akses berbeda. Admin, Siswa, dan Petugas masing-masing memiliki formulir login terpisah dan sesi yang tidak saling tertukar.

Tanpa Login

Pengunjung

Mengakses landing page (index.php) dan halaman Bantuan. Dapat melihat katalog buku per kategori, membuka detail buku, serta membaca rating dan ulasan yang sudah ada. Tidak dapat meminjam buku tanpa mendaftar terlebih dahulu.

siswa/login.php

Siswa / Anggota

Mendaftar mandiri, login ke dashboard pribadi, meminjam buku lewat alur konfirmasi bertahap, mengembalikan buku, memberi rating dan komentar setelah pengembalian, serta mencatat presensi saat membaca di tempat tanpa meminjam.

admin/login.php

Admin

Mengelola seluruh data master: tambah/ubah/hapus data buku dan anggota, memantau dan mencetak laporan seluruh transaksi, mengelola akun Petugas, serta melihat log kunjungan siswa.

petugas/login.php

Petugas

Mencatat transaksi peminjaman dan pengembalian atas nama siswa secara langsung di meja sirkulasi, melihat data buku dan anggota, memantau daftar buku yang terlambat dikembalikan, serta melihat riwayat aktivitas transaksi yang telah diprosesnya.

Struktur Folder

project/
├── admin/          # Panel Admin — kelola buku, anggota, transaksi, petugas
├── petugas/        # Panel Petugas — input peminjaman/pengembalian
├── siswa/          # Area Siswa — pinjam, kembalikan, rating, presensi
├── api/            # Endpoint notifikasi
├── config/         # Koneksi database & konstanta
├── includes/       # Auth, CSRF, sidebar, notifikasi
├── assets/         # CSS, JS, gambar, suara
├── uploads/         # Cover buku
├── bantuan.php

Setiap panel (admin/, petugas/, siswa/) memiliki file login dan logout tersendiri. Semua koneksi database dan pemeriksaan sesi login dipusatkan lewat config/database.php dan includes/auth.php, sehingga dipanggil oleh hampir seluruh halaman lewat require_once.

07 — Teknis

Keamanan

Empat mekanisme keamanan diterapkan secara konsisten di seluruh aplikasi:

  • Prepared statement (PDO) — seluruh query ke database menggunakan parameter terikat, mencegah SQL Injection.
  • Password hashing (bcrypt) — password admin, siswa, dan petugas disimpan dalam bentuk hash, tidak pernah dalam teks biasa.
  • Session terpisah per role — sesi login admin, siswa, dan petugas disimpan pada variabel session berbeda (admin_id, anggota_id, petugas_id) dan diverifikasi lewat fungsi requireAdmin(), requireSiswa(), requirePetugas() di includes/auth.php.
  • Token CSRF — dibuat per sesi dan diverifikasi pada setiap aksi yang mengubah data: hapus buku/anggota/transaksi, login, pendaftaran, proses peminjaman/pengembalian, dan pemberian rating.
08 — Menjalankan

Instalasi

1. Extract project ke folder web server (mis. htdocs/ pada XAMPP)
2. Buat database baru, misalnya db_perpustakaan
3. Import file db_perpustakaan.sql ke database yang baru dibuat
4. Buka config/database.php, lalu sesuaikan nilai berikut dengan environment kamu:

   $DB_HOST = 'localhost';
   $DB_NAME = 'db_perpustakaan';
   $DB_USER = 'root';
   $DB_PASS = '';

5. Pastikan folder uploads/ dapat ditulis oleh web server
6. Jalankan Apache & MySQL
7. Buka http://localhost/<nama-folder-project>/index.php di browser
